# 🌸 My First Machine Learning Model

This is my first Machine Learning project! 🚀

I built a simple classification model using Python and Scikit-learn to predict Iris flower species based on their measurements.

## 🧠 About the Project

The model uses the **K-Nearest Neighbors (KNN)** algorithm to classify Iris flowers into three species:

- Setosa
- Versicolor
- Virginica

## 🛠️ Technologies Used

- Python
- Pandas
- NumPy
- Scikit-learn

## ⚙️ How It Works

1. Load the Iris dataset.
2. Prepare the data using Pandas.
3. Split the dataset into training and testing sets.
4. Train a KNN classifier with 3 neighbors.
5. Evaluate the model's accuracy.
6. Make predictions on flower measurements.

## 🚀 How to Run

Install the required libraries:

```bash
pip install -r requirements.txt
```

Run the model:

```bash
python main.py
```
